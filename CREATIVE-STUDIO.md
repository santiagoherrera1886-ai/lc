# Little Caesars — Creative Studio V6

This page is a creative concept playground for the Colombia media plan. It is intentionally a prototype: it does not publish campaigns, certify stores, or show measured store visits.

## Pages
- Resumen (#summary), Territory (#territory), Audiences (#audiences), Media (#media), Simulator (#simulator), **Creative Studio (#creative)**, Sources (#sources).
- The new page is injected by studio-v6.js and styled by studio-v6.css. Both scripts are loaded after the existing V1–V5 code so older features and formulas remain intact.
- app.js route whitelist includes creative; the original sidebar/route click delegation remains in place.

## V6 interactions
- Four conceptual ideas, filtered by Meta, TikTok or Google role.
- Platform-specific in-phone ad previews; Google shows Search/Maps styling, TikTok shows dark/full-screen, and Meta shows social.
- Copy the client-ready concept/brief from Creative Studio.
- A four-image visual wall can open any concept.
- Home and Media sections link to the new studio.
